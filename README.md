A one-line Python program that writes a warm, funny, heartfelt two-line
family scene to `/output/entry.txt` — Dad's burnt Sunday toast, announced
like a weather report, and a smoke alarm that has given up objecting.

Run it with:

```sh
python3 main.py
```

Entry for the [make.fun](https://make.fun) competition
`u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2`.
